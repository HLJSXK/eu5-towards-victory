# 大科学家特质：最小实现版

## 目标

先实现一组简单的“大科学家”角色特质，让角色在担任科学院首席科学家时获得额外的“等效 ADM”。

这一版实现数值读取、显示，以及一个基础成长入口：每次完成集中研究 D 时，当前首席科学家获得或升级大科学家特质。

## 特质档位

| 特质 | 担任首席科学家时的效果 |
|---|---:|
| `tv_great_scientist_1` | 等效 ADM +20 |
| `tv_great_scientist_2` | 等效 ADM +40 |
| `tv_great_scientist_3` | 等效 ADM +60 |

底层实现复用 `category = cabinet`，并用 `custom_tags = { tv_great_scientist }` 标记为本模组的大科学家特质。特质本身不写直接 modifier，实际效果由科学院/研究/医学脚本读取。

## 当前作用范围

等效 ADM = 首席科学家的基础 `adm` + 大科学家特质加成。

当前接入位置：

- 集中研究 D 的启动门槛：至少 20 等效 ADM。
- 集中研究 D 的月度进度：等效 ADM × 0.05。
- 集中研究 D 随机事件池：按等效 ADM 的 `<20`、`20-49`、`50-79`、`>=80` 档位判断。
- 医学治疗月度进度：等效 ADM × 0.1。
- 科学院首席科学家效果卡：仍显示角色基础 ADM；特质由角色卡显示，D 进度的 IO 月度明细会单独列出特质加成。

## 获取与升级

集中研究 D 完成时，当前首席科学家自动获得或升级大科学家特质：

- 无特质 → `tv_great_scientist_1`。
- `tv_great_scientist_1` → `tv_great_scientist_2`。
- `tv_great_scientist_2` → `tv_great_scientist_3`。
- `tv_great_scientist_3` 保持最高等级。

升级逻辑会确保三个等级互斥；如果旧档或调试路径导致多个等级并存，会保留最高等级并移除低级残留。

## 暂不实现

- 大科学家专属事件线。
- 多路线特质树。
- 独立的大科学家 UI 卡片。

后续如果要扩展，可以在重大突破事件或科学院政策中加入额外授予/升级入口。
