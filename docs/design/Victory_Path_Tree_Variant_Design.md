# 胜利之路树状奖励变体设计（未来实现）

## 状态与范围

- **状态：** 设计记录，尚未实现。
- **目标：** 以树状奖励取代现行的线性五里程碑、每层三选一奖励模型。
- **适用路径：** 征服、繁荣、贸易、外交、文化、科技六条胜利之路。
- **点数：** 解锁每个奖励节点都需要消耗胜利之路点数；点数及各节点成本均为硬编码数据。具体点数来源、总量与单节点成本尚待实现阶段定义。
- **解锁规则：** 节点必须在其前置节点已解锁后才能购买。主干有五个连续节点；五个支线分别从主干的第 1、2、3 个节点分出。下文每条箭头序列完整列出该支线的前置路径，重复出现的奖励名称表示同一个已解锁前置节点。
- **记录原则：** 本文逐项保留提出时的效果和值，包括重复节点与与现行奖励不同的数值；在实现前不作平衡或效果名修正。
