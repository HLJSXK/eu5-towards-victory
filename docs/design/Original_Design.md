胜利之路由6个路径组成：征服、繁荣、贸易、外交、文化、科技
6个路径完全独立，不存在互相联动的设计
每个路径按照独立mod的规格设计，最终本项目以6个独立mod + 主mod胜利之路（包含6个子mod内容）的形式发布

# 通用
虽然6个路径不相互依赖，但其中包括一整套通用机制。胜利之路模组的独立内容其实主要体现在通用机制上
1. 胜利点：每种路径独特定义的一种变量。利用country_montly_pulse为所有国家更新
2. 胜利里程碑：胜利点达到一定阈值时，被认为达到了胜利里程碑。每条路径有5个里程碑，被称为里程碑1、里程碑2、短期胜利、里程碑4、长期胜利。相较于前三个里程碑，后两个应当难度更大。
3. 里程碑奖励：达到里程碑时，国家会触发对应的里程碑事件，并赋予国家永久性的正面修正作为奖励。胜利里程碑奖励应当体现出对应路径的独特性。
4. 主要机制：每种路径定义一种主要机制，并在达到胜利里程碑1时解锁，创建对应的国际组织。
国际组织应当是“非独特”的，因为每个玩家都通过自己的国际组织追求胜利
国际组织以角色为领袖。
主要机制的目标是大幅度扩展玩家的可玩内容。主要机制本身不应剧烈的影响游戏平衡性，而是提供给玩家额外的可操作性，从而更方便的加速自己追求对应胜利路径的进程。
5. 伟人：每种路径定义一种伟人，同时也是对应的主要机制国际组织的领袖，国际组织UI应当设计对应的按钮来任命、解雇、更换伟人。
伟人直接影响对应主要机制的推进速度，属性越高，在位时间越长，对主要机制的正面效果越强。
伟人对国家统治者形成权利威胁，这种威胁随伟人属性的提高和在位时间的延长而逐渐增大。
安排伟人不需要花费任何资源，但移除/更换伟人需要花费政府点数（即正统性、共和传统等），且花费与在位时间成非线性正相关关系，在位时间为0时无花费，在位时间无穷大时，花费为10政府点数
国际组织UI也应当设计伟人在位时间的显示，以提醒玩家

# 征服胜利
## 定位
征服胜利毫无疑问是为那些地图染色爱好者准备的
## 通用机制
胜利点：本国拥有的地点数+附庸国拥有的地点数/2
胜利里程碑：200、400、600、1200、2500
里程碑奖励：+5%训练度、+10%陆军士气、TODO
## 主要机制：总督系统
达到里程碑1时，创建“总督府”国际组织。国际组织的领袖为角色。创建后，自动将所有当前的附属国加入国际组织。
### 总督
总督指的是总管一个区域（即Province之上一级）的角色。不同于附庸国，指派总督不会产生巨大的所有权变化，而只是对省份施加特定的修正。
总督的能力直接决定了对省份施加的效果。
增加最大控制力，等于行政能力*0.1%，即最大10%
降低原产和建筑的建造花费，等于外交能力*0.2%，即最大20%
增加人群满意度，等于军事能力*0.2%，即最大20%
增加当地的阶层影响力，总督阶层即受益的阶层，等于（行政能力+外交能力+军事能力）*0.2%，即最大60%
### Tab1
国际组织Tab1定义了总督的状态。
顶部显示一个Card，作为标题，显示“xxx拥有y个总督”
接下来是y个Card，每个展示一个区域的情况。这个Card首先是区域Icon紧接着区域名，作为标题；随后是一个包裹的角色Card，这个角色Card包括角色的头像、属性、特质等信息，与原版内阁等界面使用的Card相似；最后是一行效果展示，即该总督提供的最大控制力、花费减免、人群满意度和阶层影响力数值，每个都是一个对应Icon紧接着数值，其中阶层影响力Icon应当使用总督所在的阶层。
玩家直接拥有的地点每属于一个区域，即新增一个总督，即玩家的每个地点必定属于某个总督管辖
### Tab2
国际组织Tab2定义了总督府的法律，反映对附庸国的管理制度。
使用国际组织默认的法律显示界面。
1. 附庸税收：
低税收：领袖获得：-5%附属国贡金，+5%附属国满意度
中税收（默认）：无效果
高税收：领袖获得：+5%附属国贡金，-5%附属国满意度
AI国家永远反对更高的税收，支持更低的税收。为了改出高税收，玩家必须贿赂足够多的属国。

### 伟人：大将军
大将军是一种简单的伟人机制。
玩家可以对大将军进行“训练”，从而开启一个1年时长的计数器，在此期间获得+10%宫廷花费支出，计数器结束后，发生以下随机事件之一：
1. 大将军获得+10军事能力。如果军事能力已到达100，则改为触发”世间无两“事件，为国家的君主添加3点军事能力。（49/100概率）
2. 大将军获得/增强其军事特质。不同于其他角色，大将军使用本mod独有的特质系统，即使其已有特质，也必须被特殊特质取代，见下文；如果其特质已达满级，则改为触发”百炼成钢“事件，为其添加15军事能力；如果军事能力也已到达100，则改为触发”世间无两“事件，为国家的君主添加3点军事能力。（49/100概率）
3. 大将军在训练中受伤！赋予其负面健康特质“伤疤”，如果已有该特质，则改为触发”旧伤复发“事件，导致大将军死亡（1/100概率）
4. 大将军在训练中意外去世！同样导致大将军死亡（1/100概率）
大将军的特质分为3条路线，进攻、防御和战术。每次升级时，在已有效果上叠加新效果。这在eu5中不支持，但我们可以定义多个特质，以新的替换旧的来等效实现
1. 进攻：+5%训练度、+10%士气、+10%步兵作战、+10%骑兵作战、+5%训练度、+10%士气、+1战斗中骰子
2. 防御：+0.2军事战术、+10%士气、+20%士气恢复、-20%补给消耗、+0.2军事战术、+10%士气、+1战斗中骰子
3. 战术：+10%移动速度、+10%围城能力、+10%主动性、+10%参战速度、+10%移动速度、+10%围城能力、+1战斗中骰子

1. 论证
由于奇观建设耗费巨大，且象征意义大于实际意义，几乎必然遭到国内的反对。因此玩家必须通过5场辩论来开始奇观建设。
