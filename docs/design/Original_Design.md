胜利之路由6个路径组成：征服、繁荣、贸易、外交、文化、科技
6个路径完全独立，不存在互相联动的设计
每个路径按照独立mod的规格设计，最终本项目以6个独立mod + 主mod胜利之路（包含6个子mod内容）的形式发布

# 通用
虽然6个路径不相互依赖，但其中包括一整套通用机制。胜利之路模组的独立内容其实主要体现在通用机制上
1. 胜利点：每种路径独特定义的一种变量。利用country_montly_pulse为所有国家更新
2. 胜利里程碑：胜利点达到一定阈值时，被认为达到了胜利里程碑。每条路径有5个里程碑，被称为里程碑1、里程碑2、短期胜利、里程碑4、长期胜利。相较于前三个里程碑，后两个应当难度更大。
3. 里程碑奖励：达到里程碑时，国家会触发对应的里程碑事件，并赋予国家永久性的正面修正作为奖励。胜利里程碑奖励应当体现出对应路径的独特性。
4. 主要机制：每种路径定义一种主要机制，并在达到胜利里程碑1时解锁，创建对应的国际组织。
国际组织应当是“非独特”的，因为每个玩家都通过自己的国际组织追求胜利
国际组织以角色为领袖。
主要机制的目标是大幅度扩展玩家的可玩内容。主要机制本身不应剧烈的影响游戏平衡性，而是提供给玩家额外的可操作性，从而更方便的加速自己追求对应胜利路径的进程。
5. 伟人：每种路径定义一种伟人，同时也是对应的主要机制国际组织的领袖，国际组织UI应当设计对应的按钮来任命、解雇、更换伟人。
伟人直接影响对应主要机制的推进速度，属性越高，在位时间越长，对主要机制的正面效果越强。
伟人对国家统治者形成权利威胁，这种威胁随伟人属性的提高和在位时间的延长而逐渐增大。
安排伟人不需要花费任何资源，但移除/更换伟人需要花费政府点数（即正统性、共和传统等），且花费与在位时间成非线性正相关关系，在位时间为0时无花费，在位时间无穷大时，花费为10政府点数
国际组织UI也应当设计伟人在位时间的显示，以提醒玩家

### 总督
总督指的是总管一个区域（即Province之上一级）的角色。不同于附庸国，指派总督不会产生巨大的所有权变化，而只是对省份施加特定的修正。
总督的能力直接决定了对省份施加的效果。
增加最大控制力，等于行政能力*0.1%，即最大10%
降低原产和建筑的建造花费，等于外交能力*0.2%，即最大20%
增加人群满意度，等于军事能力*0.2%，即最大20%
增加当地的阶层影响力，总督阶层即受益的阶层，等于（行政能力+外交能力+军事能力）*0.2%，即最大60%

### 独特奇观
根据历史上真实存在的奇观，为拥有特定地点的国家提供额外选项，这些独特奇观本身还是归属于某一种通用奇观，但效果更强。
### 建设阶段
通过定义国家变量，为局势内国家确认各自所在的建设阶段
1. 构想与论证
构想阶段的本质是“抽卡”，每当玩家指定一名首席工程师，他就会随机提出他认为可行的奇观，并设定角色变量（这意味着玩家切回之前的工程师是不能刷新的）。这里需要维护一个variable list是国家当前可行的奇观列表——所谓可行，就是指该奇观至少有一个允许的地点，例如一个纯内陆国家，巨港就是不被允许的。这个list在玩家制定首席工程师时重新计算。
UI显示为：Card包裹：最左侧首席工程师头像-右侧Card：纯风味文本，其中提出的奇观类型使用特殊颜色。
玩家拥有三个选项：接受（对勾Button）、驳倒（叉Button）、贿赂（钱Button），显示在上述Card的下方靠右对齐。
选择接受就会锁定奇观建设到当前提议，这使得上述UI全部隐藏，并显示一个Card展示当前锁定的奇观：居中的ICON+名称
驳倒和贿赂都会使首席工程师重新提出议案，且从variable list中移除当前议案（确保其不再被随机到）。驳倒需要10威望，贿赂需要scale=1的钱。
由于奇观建设耗费巨大，且象征意义大于实际意义，几乎必然遭到国内的反对。因此玩家必须进一步通过辩论来开始奇观建设。辩论阶段的所有UI初始不显示，只有锁定器官后才显示。
辩论的目标是填充一个“国内支持度”IO变量，以进度条显示，这个进度条使用黑色背景，蓝色填充，需要填充至100，超过100时，改为一个蓝色背景，金色填充的进度条（模拟3颜色进度条），并最多填充至200。
只要国内支持度达到100，就可以开始下一步，但也鼓励玩家填充至200
构想与论证阶段，国内支持度不会自动损失。
填充国内支持度的方式是满足三个上层阶层的要求。这表现为3个相似的行：每行开始于对应阶层的ICON，随后是Card：Line1 - 纯风味文本，表明他的需求。Line2 - 解决方案 - 风味文本，表明将执行的操作。最右侧是三个按钮：接受、驳倒、贿赂。接受则会执行显示的effect，驳倒和贿赂都会重新刷新该阶层的要求，但前者需要10威望，后者需要scale=1的钱。
每当接受一个要求，就提升20点国内支持度。
辩论期间，各有1%概率触发月度事件，分别是3个阶层的“成员宣布支持”和“出尔反尔”，+20点支持度或扣20点支持度
玩家在底部拥有两个按钮。第一：宣布结束奇观辩论。宣布结束需要至少100点支持度。宣布结束后，阶层需求部分被隐藏，构想与论证操作被锁定，并解锁测绘阶段。只要辩论结束，就会开始每月损失1点国内支持度。
第二：宣布放弃奇观建设。这只在辩论结束后可用，点击后损失10%各阶层忠诚度，大工程师宣布退隐（死亡），损失20点威望，并完全重置奇观建设的所有进度，只有我明确标识不重置的变量得到保留。
在后续阶段，无论因为何种原因导致支持度归0，都将导致“奇观建设被迫中止！”，这将损失10%各阶层忠诚度，大工程师宣布退隐（死亡），损失20点威望，并完全重置奇观建设的所有进度，只有我明确标识不重置的变量得到保留。
2. 测绘
测绘阶段决定了奇观建造的最大等级、建造成本、建造时间
玩家需要指派首席工程师前往国家内部的一个地点进行测绘，每种奇观天生就有其限制的位置。（不满足的地点根本不可选择）
圣山综合体：山、高原、丘陵
巨港：海边
凯旋轴线城市：城市、大都市
巨型陵墓园区：乡村
大灯塔：海边
水利工坊复合体：河边/湖边
矿业都市：原产品（RGO）是某种矿物，判定方式依据对应RGO的采集方式
测绘本身不花费任何资源
测绘的速度取决于首席科学家的军事能力，显示一个进度条，到100%时测绘完成
测绘的结果是3个0~100的百分数，称为规模称职度、物流称职度、组织称职度，它们由多个因素决定：
1）每种奇观天生就有其偏好，且不对玩家可见，需要玩家自行探索。这种先天的偏好性对三个称职度产生等量效果，至多产生25%的称职度
圣山综合体：山地+15%、高原+7.5%、森林+10%、树林+5%
巨港：按港口容量0~100%，线性scale 0~25%
凯旋轴线城市：按发展度0~100，线性scale 0~20%，大都市+5%
巨型陵墓园区：丘陵+15%，紧挨着城市+10%，紧挨着集镇+5%
大灯塔：按港口容量0~100%，线性scale 0~25%
水利工坊复合体：按当地已建造建筑等级0~100，线性scale 0~25%
矿业都市：按发展度0~100，线性scale 0~20%，乡村+5%
2）测绘本身的结果是完全随机的，通过3次随机产生3项称职度加值，至多产生25%的称职度
3）测绘期间，将产生月度随机事件，事件包括2类，第一类是直接增加/降低5%称职度，第二类是二选一，通过消耗某种资源增加5%称职度或是放弃。这些事件都有3个版本，对应三种称职度。可消耗的资源包括：scale=1的金钱、威望、贵族/市民/教士的10%忠诚度、被测绘地点的10%繁荣度、被测绘地点的20%人群满意度。所有事件在同一个random列表中，确保一次不发生多个，且每个事件的月度概率固定为1%
4）测绘的结果还直接受到首席工程师行政能力的影响，但影响较小，至多产生10%的称职度
5）称职度不超过100%
为了增强视觉效果，测绘开始后就以piechart+中央Icon+百分比的格式显示三种称职度，随时更新，三种称职度放置在同一行，并在下一行对齐放置三个对应的效果显示，即Icon+最大等级；Icon+建造成本；Icon+建造速度。
根据称职度，最大等级scale为1~6，建造成本scale为200%~50%，建造时间为200%~50%。
当一个地点被测绘完成后，其用于建造对应奇观的三种称职度即写入地点variable，在游戏的剩余时间不会再改变。假设玩家在测绘按钮中选择了一个已被测绘的地点，则不会重新开始测绘，而是直接展示该地点的测绘结果。
测绘完成时，为玩家弹出事件，告知测绘结果及对应的建造效果。设计三种事件文本，如果称职度较低，则建议玩家重新选择地址；较高，则表示大家都很兴奋。
玩家在底部拥有一个按钮：宣布奇观选址。仅限测绘完毕后可以点击。点击后将锁定当前测绘的地点，允许开始组织和物流/建设阶段，并根据地点称职度评级获得0/50/100点国内支持度。

4. 建设
长远来看建设UI需要精心设计，但初期先简化：
每行代表奇观的一个部分，从下到上
1）基础建设：“建设”方块按钮居左，紧接着是名字，在右侧使用6个方块合并为一个很宽的方块代表进度

4）封顶与装饰：同基础建设

建设进度不会被奇观建设的完成或中止清空，但超出单元阈值的部分会消失。这能够帮助玩家先建设一定等级的奇观，并在恰当的时候进行扩建。
只要奇观等级至少达到1，玩家就可以执行“宣布奇观建设完成”，这将摧毁物资集散地并禁用建设功能，信息Card变为各部分单元数，同时允许“仪式”阶段，并赋予20点国内支持度。

### 冥想
为科研院IO的医学tab添加“冥想”功能，与治疗相似，提供一个信息Card和一组按钮。在默认情况下，信息Card显示“选择一名角色，首席科学家将带领他走出迷途”。选择角色后，显示其角色Card。只有带有“负面特质”的角色才可被选择，这包括：

开始冥想后，还在其角色Card的下方显示一个进度条。进度条每月的增长量与治疗相同。在冥想期间，大科学家也被认为是忙碌的，不能进行其他任务。

### 本地展览
1. 至少需要5件艺术品才能举办本地展览。举办的价格变为scale=3.5的金钱。按下举办按钮时，增加select trigger，要求玩家选择本地展览的所在地。选择后会在当地建造一个独特建筑“文艺展览会”，这个建筑雇佣50位贵族，使用非常强力的维护：每月消耗各类和艺术有关的商品，总价值控制在40杜卡特。建筑的效果是：增加2点移民吸引力，-20%生产效率，-20%本地叛乱度。
2. 添加IO变量——展览热情。开始展览时，获得80展览热情，展览热情的上限为100。展览热情每月自然衰减8点。玩家拥有多种维持展览热情的行动。当展览热情归零时，本地展览即结束。本地展览结束后，设置12个月的展览冷却时间。本地展览结束时需要触发事件告知，提供奖励，并拆除特殊建筑。
3. 为本地展览的信息显示部分添加进度条，更直观的展示展览热情。设计为“冷淡”Icon - 进度条 - “热情”Icon。
4. 追踪本地展览的持续时间。最终展览产出的文化影响力按每个持续月份0.5点计算。此外，以12个月、18个月、24个月为界，对本次展览进行评级（4个等级），并以不同的结束事件体现这种差异。
5. 在UI上追踪本地展览目前已持续多久，以及达到了第几级展览等级
6. 1级展览在持续月份收益外提供-3点文化影响力奖励，且因展览反响平平，反而会损失10点威望。2级展览提供0点文化影响力奖励。3级展览提供3点奖励，且提供10点威望。4级展览提供6点奖励，15点威望，为展览地提供0.25发展度，10%繁荣度，并施加一个持续1年的buff：增加2点移民吸引力，+30%生产效率，-20%本地叛乱度。
7. 展览的第1控制机制：增加更多展品！
1）追踪已投入的展品数量，在UI显示。
2）一个新的按钮，这个按钮仅当（拥有展品数 - 已投入展品数）> x时才被允许使用。第一次使用时，x为5；第二次为10；此后固定为20。
3）投入更多展品会增加固定20点热情
8. 展览的第2控制机制：月度事件。
1）每月各有1%概率触发事件，每个事件对应一种资源
2）所有事件遵循统一设计规范——代换，即两个选项分别是立即消耗一种资源换取10点热情，或是失去5点热情。
3）可用于代换的资源包括：0.5缩放系数的金钱、威望、贵族/教士/市民/平民的阶层满意度、稳定度、正统性、展览举办地的0.25发展度、展览举办地的20%繁荣度。
4）你需要帮助我完成具体数值填写，并仔细撰写漂亮的风味化文本。
9. 展览的第3控制机制：主要行动组。
1）主要行动组的按钮均平时隐藏，只有展览期间可见（potential控制）
2）行动1：国王亲临！这将立即增加10点热情，并随机触发4个事件之一：国王获得3点全属性、国王失去3点全属性、获得5点正统性、失去5点正统性。该选项在展览期间仅限使用一次。
3）行动2：宣扬激进的艺术理念！这将随机触发4个事件之一：获得20热情并失去7点稳定、获得10热情、失去5热情、一件随机艺术品被摧毁。该选项有1年冷却时间。使用Action的标准冷却时间定义，而非自定义变量。
4）行动3：扩大展览规模！这将失去scale=2.0的金钱，并使用一个select trigger选定次要地点（不允许选择同一地点），选定后在次要地点建造相同建筑。获得10点热情。该选项在展览期间仅限使用一次。
5）行动4：王室贩卖艺术品！这将摧毁一件随机艺术品，并获得scale=1.0的金钱。1年冷却
6）行动5：招揽更多艺术家！这将失去10点威望，并随机触发4个事件之一：（高概率）获得一位平平无奇的艺术家，技艺不大于30；（低概率）获得一位技艺超群的艺术家，技艺至少70；（低概率）无人问津。1年冷却
7）行动6：邀请国外艺术家参与！这将使用select trigger选定一个国家，且只有拥有至少一位艺术家的国家可被选择。选择后，目标国家将收到一条事件，选定随即一位艺术家作为事件目标，事件表示这名艺术家受到了邀请国的邀请，你是否同意其出访？选择同意将使得这位艺术家移动至邀请国（这里注意同步处理其他文化展览IO机制），并获得10点威望，且展览结束后为被邀请国触发事件，该艺术家返回，此外选择同意将为邀请国触发事件显示对方同意；选择不同意出访则为邀请国触发事件显示对方不同意。如果同意，则获得10点热情。AI通过对邀请国的好感度选择是否接受，只要好感大于50，就会选择接受，否则不接受。该选项在展览期间仅限使用一次，因此你可以使用国家级变量追踪被邀请的艺术家。
8）行动7：指定镇馆之宝！这将失去20点威望，并提升一件艺术品10%的品质，随后获得10点热情。该选项在展览期间仅限使用一次
9）行动8：举行现场创作大会！这将随机触发5个事件之一：国家某位艺术家获得0.05技艺、国家某位艺术家获得-0.05技艺、获得10点热情、（低概率）国家某位艺术家死亡并产生一件艺术品、（低概率）产生一件艺术品
