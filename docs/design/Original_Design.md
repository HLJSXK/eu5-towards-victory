胜利之路由6个路径组成：征服、繁荣、贸易、外交、文化、科技
6个路径完全独立，不存在互相联动的设计
每个路径按照独立mod的规格设计，最终本项目以6个独立mod + 主mod胜利之路（包含6个子mod内容）的形式发布

# 通用
虽然6个路径不相互依赖，但其中包括一整套通用机制。胜利之路模组的独立内容其实主要体现在通用机制上
1. 胜利点：每种路径独特定义的一种变量。利用country_montly_pulse为所有国家更新
2. 胜利里程碑：胜利点达到一定阈值时，被认为达到了胜利里程碑。每条路径有5个里程碑，被称为里程碑1、里程碑2、短期胜利、里程碑4、长期胜利。相较于前三个里程碑，后两个应当难度更大。
3. 里程碑奖励：达到里程碑时，国家会触发对应的里程碑事件，并赋予国家永久性的正面修正作为奖励。胜利里程碑奖励应当体现出对应路径的独特性。
4. 主要机制：每种路径定义一种主要机制，并在达到胜利里程碑1时解锁，创建对应的国际组织。
国际组织应当是“非独特”的，因为每个玩家都通过自己的国际组织追求胜利
国际组织以角色为领袖。
主要机制的目标是大幅度扩展玩家的可玩内容。主要机制本身不应剧烈的影响游戏平衡性，而是提供给玩家额外的可操作性，从而更方便的加速自己追求对应胜利路径的进程。
5. 伟人：每种路径定义一种伟人，同时也是对应的主要机制国际组织的领袖，国际组织UI应当设计对应的按钮来任命、解雇、更换伟人。
伟人直接影响对应主要机制的推进速度，属性越高，在位时间越长，对主要机制的正面效果越强。
伟人对国家统治者形成权利威胁，这种威胁随伟人属性的提高和在位时间的延长而逐渐增大。
安排伟人不需要花费任何资源，但移除/更换伟人需要花费政府点数（即正统性、共和传统等），且花费与在位时间成非线性正相关关系，在位时间为0时无花费，在位时间无穷大时，花费为10政府点数
国际组织UI也应当设计伟人在位时间的显示，以提醒玩家

### 总督
总督指的是总管一个区域（即Province之上一级）的角色。不同于附庸国，指派总督不会产生巨大的所有权变化，而只是对省份施加特定的修正。
总督的能力直接决定了对省份施加的效果。
增加最大控制力，等于行政能力*0.1%，即最大10%
降低原产和建筑的建造花费，等于外交能力*0.2%，即最大20%
增加人群满意度，等于军事能力*0.2%，即最大20%
增加当地的阶层影响力，总督阶层即受益的阶层，等于（行政能力+外交能力+军事能力）*0.2%，即最大60%

玩家直接拥有的地点每属于一个区域，即新增一个总督，即玩家的每个地点必定属于某个总督管辖

### 本地展览
1. 至少需要5件艺术品才能举办本地展览。举办的价格变为scale=3.5的金钱。按下举办按钮时，增加select trigger，要求玩家选择本地展览的所在地。选择后会在当地建造一个独特建筑“文艺展览会”，这个建筑雇佣50位贵族，使用非常强力的维护：每月消耗各类和艺术有关的商品，总价值控制在40杜卡特。建筑的效果是：增加2点移民吸引力，-20%生产效率，-20%本地叛乱度。
2. 添加IO变量——展览热情。开始展览时，获得80展览热情，展览热情的上限为100。展览热情每月自然衰减12点。玩家拥有多种维持展览热情的行动。当展览热情归零时，本地展览即结束。本地展览结束后，设置12个月的展览冷却时间。本地展览结束时需要触发事件告知，提供奖励，并拆除特殊建筑。
3. 为本地展览的信息显示部分添加进度条，更直观的展示展览热情。设计为“冷淡”Icon - 进度条 - “热情”Icon。
4. 追踪本地展览的持续时间。最终展览产出的文化影响力正比于持续时间。此外，以12个月、18个月、24个月为界，对本次展览进行评级（4个等级），并以不同的结束事件体现这种差异。
5. 在UI上追踪本地展览目前已持续多久，以及达到了第几级展览等级
6. 1级展览只提供文化影响力，且因展览反响平平，反而会损失10点威望。2级展览除线性文化影响力收益外，额外提供2点文化影响力奖励。3级展览提供4点奖励，且提供10点威望。4级展览提供6点奖励，15点威望，为展览地提供0.25发展度，10%繁荣度，并施加一个持续1年的buff：增加2点移民吸引力，+30%生产效率，-20%本地叛乱度。

1）追踪已投入的展品数量，在UI显示。
2）一个新的按钮，这个按钮仅当（拥有展品数 - 已投入展品数）> x时才被允许使用。第一次使用时，x为5；第二次为10；此后固定为20。
3）投入更多展品会增加固定20点热情

1）每月各有1%概率触发事件，每个事件对应一种资源
2）所有事件遵循统一设计规范——代换，即两个选项分别是立即消耗一种资源换取10点热情，或是失去5点热情。

8）行动7：指定镇馆之宝！这将失去20点威望，并提升一件艺术品10%的品质，随后获得10点热情。该选项在展览期间仅限使用一次
9）行动8：举行现场创作大会！这将随机触发5个事件之一：国家某位艺术家获得0.05技艺、国家某位艺术家获得-0.05技艺、获得10点热情、（低概率）国家某位艺术家死亡并产生一件艺术品、（低概率）产生一件艺术品
