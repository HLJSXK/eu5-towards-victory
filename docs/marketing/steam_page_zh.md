# Steam 创意工坊页面 — 中文（从简）

**标题：** Towards Victory - 伟大工程

---

原版奇观只是一段历史小知识，没有任何实际效果。**伟大工程** 把它变成一项真正需要举国之力推进的工程。

**模组内容：**
- 新增国际组织"工程部"，统一管理奇观的建造流程
- **54 种通用奇观**，任何国家均可建造；另有 **123 座历史独特奇观**，对应真实历史地点（亚历山大的法罗斯灯塔、君士坦丁堡的圣索菲亚大教堂、库姆的波斯坎儿井等）
- **六阶段建造流程**：构想 → 论证 → 勘测 → 建设 → 仪式 → 落成——提出方案、争取国内支持、勘测选址、投入建设，最后选择决定奇观最终效果的仪式
- 配套的 **奇观图鉴网站**，可在世界地图上浏览全部独特奇观

**前置要求：** Community Mod Framework 2.x。完全独立，不依赖任何其他模组。

可单独游玩，也可搭配《胜利条件》本体一起使用。
