[h2][i]从构想到落成，六个阶段，一座国家级纪念工程。[/i][/h2]

[img]https://i.imgur.com/qVex6lv.png[/img]

原版 EU5 的奇观只是装饰，一段风味小知识，仅此而已。[b]伟大工程[/b] 将它们变成一项完整的国家工程：由专门的组织统筹流程，每个阶段都需要付出实际代价，最终落成时更会带来永久的全国性回报。

[img]https://i.imgur.com/haIXGbe.png[/img]

[i]工程部面板，整个建造流程都在这里追踪。[/i]
[list]
[*] 独立的国际组织 [b]工程部[/b]，负责管理整个奇观建造流程
[*] [b]56 种通用奇观[/b]可供任何国家建造，另有 [b]136 座历史独特奇观[/b]绑定其真实历史地点，包括亚历山大的法罗斯灯塔、君士坦丁堡的圣索菲亚大教堂、库姆的波斯坎儿井等
[*] 完整的 [b]六阶段建造流程[/b]：构想 → 论证 → 勘测 → 建设 → 仪式 → 落成
[*] 专属的 [b]地图模式[/b]，为全世界已建成的奇观标色。你可以规划自己的建造，也可以侦察他国已建成的奇观，将其作为征服目标
[*] 使用 [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3692202776] Community Mod Framework (CMF) [/url] 的游戏内菜单功能，可以控制伟大工程的建造难度
[*] 配套的 [b]奇观图鉴[/b]网站，可在游戏外的世界地图上浏览全部独特奇观
[/list]

[img]https://i.imgur.com/8L5HRD1.png[/img]

[i]建设，将建材投入地基、主体、功能与装饰四个部分。[/i]
[olist]
[*] [b]构想[/b]，你的伟大工程师会根据国家现状提出一项奇观方案。你可以接受方案、花费威望要求修改，或投入资金获取一组全新的方案
[*] [b]论证[/b]，在建设开始前争取贵族、市民与教会的支持
[*] [b]勘测[/b]，从规模、物流和组织度三方面为选址评分，永久决定奇观的最高等级、成本与建造时间
[*] [b]建设[/b]，建造配套基础设施，并将建材投入奇观的四个组成部分
[*] [b]仪式[/b]，通用奇观可从 3 种风格中选择；独特奇观则会举行根据其历史定制的仪式。这一步才真正决定奇观的最终效果
[*] [b]落成[/b]，奇观正式建成，你会获得全国性的庆典增益，落成消息也会作为世界新闻公开播报
[/olist]
