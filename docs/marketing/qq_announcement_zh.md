# QQ 群通知（中文）

【模组发布】伟大工程 - Great Project

原版 EU5 的奇观一直是个摆设，点开就是一段历史小知识，没有任何实际效果。这次我们做了个模组，把它改成了真正要投入建造的国家工程。

模组内容：
- 新增国际组织"工程部"，负责管理整个奇观建造流程
- 54 种通用奇观 + 123 座历史独特奇观（绑定真实历史地点，比如波斯坎儿井在库姆，龙江船厂在江阴）
- 完整六阶段流程：构想 → 论证 → 勘测 → 建设 → 仪式 → 落成
- 最后的仪式选择会真正决定奇观带来的效果
- 另外配了一个奇观图鉴网站，可以在地图上直接浏览全部独特奇观

只需要 Community Mod Framework 2.x 一个前置，完全独立，不需要本体《胜利条件》也能玩，也可以搭配本体一起用。
