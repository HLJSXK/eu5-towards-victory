08/05 [Great Project](https://steamcommunity.com/sharedfiles/filedetails/?id=3766375743) Update

This is mostly a QoL update based on player requests, with a smaller content pass for Asia.

- Added **2 new generic wonders** and **13 historical unique wonders** in Asia and nearby regions.
- Existing wonders can now be **demolished**. Completed wonders can also be turned off temporarily, which gives a simple workaround for value-conflict situations.
- Worksites now **slow down when required inputs are missing**, so material shortages matter during construction.
- Added **top-right UI alerts** when the Engineering Department needs your attention.
- Rebalanced several clearly problematic wonder bonuses, especially **market attraction** and **granary-style** effects.
- Added [CMF](https://steamcommunity.com/sharedfiles/filedetails/?id=3692202776) in-game menu options to adjust Great Project construction difficulty to some extent.
- Built in the [Glorp UI](https://steamcommunity.com/sharedfiles/filedetails/?id=3601047146) version of `location_window`. Load Great Project below Glorp UI, and below [Construction Manager](https://steamcommunity.com/sharedfiles/filedetails/?id=3736668860) if you use it, to get the merged location UI.
