## MEIOU and Taxes Compatibility

**Title:** Great Project - MEIOU and Taxes Compatibility

```bbcode
[h2]What this does[/h2]
[list]
[*] [b]Great Project[/b] and [b]MEIOU and Taxes[/b] both fully override [i]location_window.gui[/i] (the location panel). Enabling both without this patch means whichever mod loads last silently wins, and the other mod's location panel changes disappear — no error, no warning.
[*] This submod merges the two: it takes M&T's own location window and adds Great Project's wonder badge and tooltip overlay on top, so both mods' location panel features work together.
[/list]

[h2]How to use[/h2]
[olist]
[*] Subscribe to and enable [b][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3692202776]Community Mod Framework (CMF)[/url][/b] 2.x
[*] Subscribe to and enable [b][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3766869023]Great Project[/url][/b]
[*] Subscribe to and enable [b][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3735059838]MEIOU and Taxes[/url][/b]
[*] Subscribe to and enable [b]this compatibility patch[/b], placed [b]below both[/b] of the above in your playset's load order
[/olist]

[h2]Links[/h2]
[list]
[*] [b][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3766869023]Great Project[/url][/b] — the main mod this patch is for.
[/list]
```

## Prosper or Perish Compatibility

**Title:** Great Project - Prosper or Perish Compatibility

```bbcode
[h2]What this does[/h2]
[list]
[*] [b]Great Project[/b] and [b]Prosper or Perish[/b] both fully override [i]encyclopedia_lateralview.gui[/i] (the Europedia panel) to add their own custom sidebar tab. Enabling both without this patch means whichever mod loads last silently wins, and the other mod's Europedia tab disappears entirely — no error, no warning.
[*] This submod merges the two tabs onto one shared toggle, so both Great Project's and Prosper or Perish's Europedia tabs open correctly and exit back to the vanilla page list as expected.
[/list]

[h2]How to use[/h2]
[olist]
[*] Subscribe to and enable [b][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3692202776]Community Mod Framework (CMF)[/url][/b] 2.x

[*] Subscribe to and enable [b][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3613232232]Prosper or Perish[/url][/b]
[*] Subscribe to and enable [b]this compatibility patch[/b], placed [b]below both[/b] of the above in your playset's load order
[/olist]

[h2]Links[/h2]
[list]
[*] [b][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3766869023]Great Project[/url][/b] — the main mod this patch is for.
[/list]
```
