## 制作备注

- 全片建议 BGM 用渐强的史诗弦乐，在"阶段四·建设"处配合延时摄影风格剪辑做情绪高点。
- 独特奇观示例（波斯坎儿井、龙江船厂）的地点信息基于最新数据（分别位于库姆、江阴），如后续再调整地点需同步更新旁白。
- Steam 创意工坊链接需在发布前确认页面已上线后再补入片尾字幕/评论区，避免录制时页面尚未生成导致口播与画面对不上。
- 全片刻意不提及《胜利条件》本体的六条胜利路线，伟大工程作为独立可玩模组呈现。
- 模组名（伟大工程 / Great Project）与游戏内国际组织名（工程部）刻意区分：标题卡、结尾 CTA 等"模组品牌"场景用"伟大工程"，涉及游戏内 IO 面板截图/UI 文案的场景仍用"工程部"，避免与实际游戏画面对不上。
