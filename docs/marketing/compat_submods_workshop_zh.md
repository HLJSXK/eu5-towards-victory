## MEIOU and Taxes 兼容补丁

**标题：** Great Project - MEIOU and Taxes Compatibility

```bbcode
[h2]这个模组是做什么的[/h2]
[list]
[*] [b]Great Project[/b] 和 [b]MEIOU and Taxes[/b] 都整份覆写了 [i]location_window.gui[/i]（位置面板）。如果不装这个补丁就同时启用两者，谁在加载顺序里靠后谁就会完全生效，另一个模组对位置面板的修改会直接消失——没有报错，也没有警告。
[*] 本子模组把两者合并：以 M&T 自己的位置窗口为基础，叠加 Great Project 的奇观徽标与提示浮窗，让两个模组的位置面板功能同时生效。
[/list]

[h2]使用方法[/h2]
[olist]
[*] 订阅并启用 [b][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3692202776]Community Mod Framework (CMF)[/url][/b] 2.x
[*] 订阅并启用 [b][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3766869023]Great Project[/url][/b]
[*] 订阅并启用 [b][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3735059838]MEIOU and Taxes[/url][/b]
[*] 订阅并启用[b]本兼容补丁[/b]，在你的模组列表加载顺序中放在[b]以上两者之下[/b]
[/olist]

[h2]相关链接[/h2]
[list]
[*] [b][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3766869023]Great Project[/url][/b] —— 本补丁所兼容的主模组。
[/list]
```

## Prosper or Perish 兼容补丁

**标题：** Great Project - Prosper or Perish Compatibility

```bbcode
[h2]这个模组是做什么的[/h2]
[list]
[*] [b]Great Project[/b] 和 [b]Prosper or Perish[/b] 都整份覆写了 [i]encyclopedia_lateralview.gui[/i]（Europedia 百科面板），各自加了一个自定义侧边栏标签页。如果不装这个补丁就同时启用两者，谁在加载顺序里靠后谁就会完全生效，另一个模组的 Europedia 标签页会直接彻底消失——没有报错，也没有警告。
[*] 本子模组把两个标签页合并到同一套切换开关上，让 Great Project 和 Prosper or Perish 的 Europedia 标签页都能正常打开，也都能正常退回原版页面列表。
[/list]

[h2]使用方法[/h2]
[olist]
[*] 订阅并启用 [b][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3692202776]Community Mod Framework (CMF)[/url][/b] 2.x
[*] 订阅并启用 [b][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3766869023]Great Project[/url][/b]
[*] 订阅并启用 [b][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3613232232]Prosper or Perish[/url][/b]
[*] 订阅并启用[b]本兼容补丁[/b]，在你的模组列表加载顺序中放在[b]以上两者之下[/b]
[/olist]

[h2]相关链接[/h2]
```
