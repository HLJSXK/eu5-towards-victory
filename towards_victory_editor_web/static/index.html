Towards Victory 编辑器

奖励/Modifier/任务池 基础单位编辑器

编辑 data/cost_reward_units.yaml —— 一套独立于任何具体机制的底层数值目录， 按国家级/本地级/角色级一次性奖励 + 国家级/本地级持续 modifier 五个类别分页展示；国家级条目也可记录非缩放的布尔解锁， 供项目中未来的多个系统查表使用。不单独存代价（cost）：需要代价时，取对应奖励（reward）行 value 的相反数即可（country_reward.inflation 方向相反）。 同时编辑 data/task_pool.yaml —— 与之并列的独立任务池目录（见 Cost_Reward_Unit_Concepts.md 第 6 节）， 按 on_action 型任务 / Trigger 型任务两个类别分页展示，同样不存奖励，只记录"需要发生什么"/ "需要达到什么状态"以及引擎侧的检测方式。 奇观建设随机事件与奇观自身的 modifier 数据分别维护在自己独立的文件中 （data/wonder_construction_events.yaml、data/wonder_base_modifiers.yaml 等），不引用此处； 奇观本身请继续使用"奇观本地化编辑器"标签页。
