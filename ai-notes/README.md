# AI Notes

This directory stores durable notes for AI-to-AI collaboration.

- `reviews/`: code review findings, risks, and validation notes.
- `handoffs/`: actionable task briefs for the next AI or contributor.
- `tasks/`: planned work items and pre-implementation analysis.
- `decisions/`: longer-lived project decisions and conventions.
- `rules/`: reusable instructions that AIs should follow during development and CR.

Keep review files evidence-focused. Put implementation instructions and task priority in handoff files.
